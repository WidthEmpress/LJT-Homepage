# LJT-Homepage

Personal academic homepage for **Junteng Liu**, built with the Academic Pages Jekyll template.

## Site Structure

- **About / Home:** `_pages/about.md`
- **Publications page:** `_pages/publications.html`
- **Publication records:** `_publications/`

The homepage presents Junteng Liu's academic background, research experience, publications, skills and research interests, and contact information. Publications are recorded both on the About page and on the Publications subpage.

## Local Preview

```bash
bundle install
bundle exec jekyll serve
```

The site is configured for the project Pages URL `https://widthempress.github.io/LJT-Homepage/`.
